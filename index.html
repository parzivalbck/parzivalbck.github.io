About

I'm an Android developer from Ashgabat who ships full products, not just screens. Over the last three years I've taken apps from an empty module to release on both mobile and Android TV — owning the architecture, the streaming layer, and the UI on each form factor.

My default is clean, multi-module architecture: a shared Kotlin domain layer feeding platform-specific UI, so the same business logic powers a Compose phone app and a Leanback TV experience. I care about the details that users never see but always feel — smooth paging, resilient media playback, and state that behaves.

I work comfortably across the modern Jetpack stack and enjoy the harder problems: media streaming with Media3/ExoPlayer, offline-first data with Room, and dependency graphs that stay sane as a codebase grows.
